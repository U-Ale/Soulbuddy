O EcoFuture é uma plataforma web interativa criada para incentivar hábitos sustentáveis através de gamificação e inteligência artificial.

O sistema possui:
- dashboard de progresso;
- ranking de usuários;
- missões ecológicas;
- chat IA sustentável;
- sistema visual futurista;
- interface responsiva para mobile.

O objetivo do projeto é tornar a sustentabilidade mais moderna, acessível e divertida utilizando tecnologia e experiência do usuário.
